# 🎬 Cine Cocais — Frontend

Interface web do projeto cultural Cine Cocais, desenvolvido com Vue 3 + Vite + Tailwind CSS.

---


### 1. Clone o repositório

```bash
git clone https://github.com/SEU_USUARIO/cinecocaisfrontend.git
cd cinecocaisfrontend
```

### 2. Instale as dependências

```bash
npm install
```

### 3. Rode o servidor de desenvolvimento

```bash
npm run dev
```

### 4. Acesse no navegador

```
http://localhost:5173
```

---

## ⚙️ Tecnologias Utilizadas

- **Vue 3** — Framework JavaScript com Composition API
- **Vite** — Build tool e servidor de desenvolvimento
- **Vue Router 4** — Gerenciamento de rotas SPA
- **Pinia** — Gerenciamento de estado global
- **Tailwind CSS v3** — Estilização utilitária
- **Axios** — Requisições HTTP para a API
